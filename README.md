# Tomestone Search

A Dalamud plugin for Final Fantasy XIV that adds context menu options
to open player profiles on Tomestone.gg.

## Features
- Right-click player → Open on Tomestone
- Works on other players and yourself
- Uses home world detection
- Opens in default browser

## Installation (Private Repo)
1. Build the plugin
2. Host the repo (GitHub/GitLab)
3. Add the repo URL in Dalamud:
   - `/xlsettings`
   - Experimental → Custom Plugin Repositories

## Notes
Private plugin – not distributed via official Dalamud repos.
